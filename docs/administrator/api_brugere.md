# API-brugere

På denne side kan du se en oversigt over de API-brugere, som findes i OpenPostbud.

![Oversigt]({{ "assets/images/administrator/api_bruger_oversigt.png" | relative_url }})

## Ny API-bruger

Hvis du klikker på 'Ny API Bruger' vil du få vist denne popup. Her skal du indtaste navnet
på den nye bruger. Navnet er kun til at kunne genkende brugeren senere og bruges ikke til
andet.

![Ny API Bruger]({{ "assets/images/administrator/ny_api_bruger.png" | relative_url }})

Efter du har indtastet navnet og trykket 'Ok', bliver denne popup vist.

__BEMÆRK__: Det er vigtigt, at du kopierer API-brugerens nøgle nu, da du ikke kan
se den igen senere.

Denne nøgle skal bruges hver gang API'et skal tilgås.

![Ny API Bruger Kode]({{ "assets/images/administrator/ny_api_bruger_kode.png" | relative_url }})

## Slet API-bruger

Hvis du klikker på en API-bruger i oversigten får du vist denne popup, hvor
du kan slette API-brugeren permanent.

![Slet API Bruger]({{ "assets/images/administrator/slet_api_bruger.png" | relative_url }})
